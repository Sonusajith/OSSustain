## Project Summary
OSSustain estimates the risk of significant contribution-activity decline over 90 days for public GitHub repositories, and studies whether contributor, newcomer-retention, and responsiveness signals improve prediction beyond activity-only features. Stack: Python pipeline → PostgreSQL → Spring Boot read API → React + TypeScript dashboard. See `PRD.md` and `Architecture.md`.
