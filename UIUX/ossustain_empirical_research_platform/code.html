Methodological Foundations

Predictive Constraints & Epistemic Transparency

Standard open-source health scores suffer from lookahead leakage and survivorship bias. OSSustain isolates genuine prospective warning indicators through strict counterfactual accounting.

01 // OBSERVATIONAL TRAP troubleshoot

The Predictive Gap

Superficial metrics (GitHub stars, aggregate forks, un-curated commit tallies) camouflage maintainer exhaustion. Core contributors routinely abandon active triage 60–120 days before gross repository commits register a measurable drop.

Empirical Finding:
Stars correlate with historical popularity (r = 0.81), but yield near-zero predictive power for 90d decline (ΔPR-AUC = +0.003).
02 // CAUSALITY SAFEGUARDS timelapse

Leakage-Safe Temporal Protocol

Random k-fold validation creates catastrophic temporal leakage in time-series panel data. Our architecture enforces strict 90-day purge gaps between chronological observation cuts and evaluation periods to eliminate right-censoring leakage.

Validation Architecture:
5-fold chronological rolling-origin evaluation. No test-fold issue or PR resolution is visible to the feature extractor.
03 // PEER-REVIEW ETHICS balance

Honest Null-Result Reporting

Negative econometric outcomes are reported with equal rigor. We explicitly document domains where non-activity metrics fail to improve baselines, resisting publication bias and p-hacking in open scientific benchmarks.

Null Hypothesis Confirmed:
In large repositories (>50k LOC), organizational sponsor change yields no incremental signal over simple 30d PR review latency.

Taxonomy of Predictive Factors

Four Empirical Feature Domains Under Hypothesis Testing

Each domain is evaluated both as an isolated regressor and within an ensemble architecture to establish incremental information gain (SHAP values and Permutation Feature Importance).

01

Activity Dynamics

Evaluates raw velocity while separating automated bot commits from verified human authorship across multiple trailing windows.

  • Non-bot commit velocity (30d/90d)
  • Merged Pull Request cadence
  • Issue triage closure rates

Contributor Diversity

Quantifies concentration risk and single-point-of-failure exposure across organizational and maintainer networks.

  • Gini coefficient of commit distribution
  • Empirical Bus Factor calculation
  • Multi-institutional affiliation ratio

03

Newcomer Retention

Tracks the survival probability of first-time patch submitters progressing to second and third merged contributions.

  • 90-day second-patch transition rate
  • First contribution rejection latency
  • Right-censored cohort survival hazard

Review Responsiveness

Measures community friction and institutional bandwidth via non-automated review speed and merge queue dynamics.

  • Median time to initial human review
  • 95th percentile PR stagnant wait time
  • Unanswered external issue quotient

Formal Operationalization

The 90-Day Activity Collapse Binary Target

We define a critical sustainability event not through subjective opinions, but through an econometric decline threshold applied strictly against the repository’s historical reference baseline:

Ground-Truth Target Function $Y_t$:
Y_{t} = \mathbb{I}\left( \text{Activity}_{[t, \, t+90d)} \le \theta \times \text{Activity}_{[t-90d, \, t)} \right)
where θ = 0.50 (50% contraction parameter)
Activity = Composite human commit count + merged PR volume + triage resolutions

Repositories with baseline activity below $\lambda = 5$ actions/month are excluded to safeguard against small-sample boundary distortions.
